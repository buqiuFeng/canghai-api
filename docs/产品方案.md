沧海 API 是一个**免费、开源、AI 驱动的 API 开发平台**，定位是 Postman / Insomnia / Hoppscotch 的现代替代品，官方宣称所有核心功能永久免费、支持离线运行与私有部署，并内置可接入自有大模型的 AI Agent。下面这份清单按 AI 开发的实际使用场景分组整理。

## 🤖 AI 原生能力（AI 开发最核心的差异点）

- **内置 AI Agent**：可自动生成 API 请求、管理变量、编排工作流，覆盖 API 设计 → 测试 → 调试全流程
- **接入自有大模型**：兼容 OpenAI 兼容 API，**可对接自己部署的 LLM**，在离线/内网环境中也能用 AI 辅助
- **AI 对话助手**：内置对话功能，支持 OpenAI 兼容接口
- **SSE 流式输出原生支持**：内置 Server-Sent Events 支持，可实时接收、解析、可视化展示流式数据块——**特别适合调试 LLM 流式接口、Agent 工具调用返回**

> 💡 对 AI 开发来说，SSE + 自有 LLM 接入 + AI 生成请求这三件事组合在一起，意味着你可以把它当成"LLM API 的调试台 + Agent 工具接口的测试台"。

## 🔌 接口调试与协议支持

- **HTTP / RESTful**：GET / POST / PUT / DELETE / PATCH / HEAD / OPTIONS 全方法，HTTP/1.1 与 HTTP/2
- **请求体类型全覆盖**：JSON、FormData、URL-encoded、Binary
- **WebSocket 测试**：完整的连接管理与消息收发
- **Socket.IO / gRPC / MQTT**：扩展协议支持
- **Query / Path 参数、自动 Content-Type、Cookie 管理**
- **前置/后置脚本**：Pre/Post request scripts
- **本地服务 / CORS 调试**
- **请求历史**：完整请求历史 + 单个节点历史，回收站

## 🎭 Mock 服务

- **HTTP / WebSocket / SSE Mock Server**：内置 Mock，支持条件脚本
- 可用于在 LLM 后端还没开发完时，先 Mock 出 Agent 工具接口、流式返回接口，让前端或 Agent 框架先跑起来

## 🔐 变量与环境系统

- **四层作用域变量**：临时 / 本地 / 环境 / 全局，支持 `{{变量名}}` 语法
- 不同环境（dev / staging / prod）切换 API base_url、API Key 等，对调 LLM 不同环境 endpoint 很实用

## 👥 团队协作与治理

- **Workspace 与项目管理**、文件夹管理
- **RBAC 角色权限**：读 / 写 / 管理员角色，项目级细粒度权限
- **评论 / 讨论**、操作审计日志、变更追踪
- **无限团队与成员**
- **操作历史与版本回退**：接口任意版本数据对比、删除还原

## 📴 离线、自部署与数据主权

- **离线优先**：全功能离线运行，数据存本地 IndexedDB，无需服务端
- **一键 Docker 部署**：`docker compose up -d` 即可，数据完全自控
- **本地优先 + 联机协同无缝切换**：离线数据可双向同步到线上
- **适合私网、受限网络、企业内网 AI 开发环境**

## 🔄 生态兼容与数据迁移

- **OpenAPI 3.x 原生导入/导出**
- **可从 Postman / Insomnia / Hoppscotch / Swagger / YApi / RAP2 / Eolinker / DOClever / cURL** 导入
- **导出 HTML / JSON / PDF** 离线文档
- **国际化**：简中 / 繁中 / 英文 / 日文
- **MIT 开源协议**，可自由 fork 二次开发

## 🎯 AI 开发推荐的使用组合

如果你做 AI 应用 / Agent 开发，最值得优先用起来的几块：

1. **AI Agent + 自有 LLM 接入** → 用 沧海 API 做 LLM API 的调试与测试用例生成
2. **SSE 流式调试** → 直接看 LLM token 流式返回、Agent 中间步骤
3. **Mock Server** → 后端 LLM 服务没就绪时，Mock 出 Chat Completions / 工具调用响应
4. **WebSocket + gRPC** → 调试 Agent 的长连接通信、推理服务 RPC
5. **Docker 私有部署** → 把含 API Key、内部 Endpoint 的项目放在公司内网，不泄露
6. **变量系统 + 环境切换** → dev / prod 的 LLM endpoint、API Key 隔离管理
7. **OpenAPI 导入** → 把后端 AI 服务的 OpenAPI 文档一键导入，立刻获得可调试的请求模板

> ⚠️ 一点提醒：沧海 API 的"完全免费、开源"是官方在当前版本下的承诺，如果用于企业生产环境，建议锁定具体版本并通过 Docker 自部署，避免后续版本策略变化影响。
